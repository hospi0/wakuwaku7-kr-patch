세가 새턴 일본판 **와쿠와쿠 7(Waku Waku 7)** 한글 패치입니다.

## 바뀌는 것

- 승부 전·승리·패배 대사 말풍선 전체
- 오프닝 스토리 문구·노래 가사·캐릭터 소개·조작 설명·거대 보스전 대사
- 캐릭터별 엔딩 대사
- 캐릭터 선택 화면 기술표(기술 이름)
- 확장 RAM 카트리지 경고·백업 RAM 용량 부족 안내 화면
- 타이틀 로고 «두근두근7»(그림 글자) · 위 영문 «DUGUN DUGUN SEVEN»

## 알려진 점

- 음성·노래는 원본 일본어 그대로입니다.
- 확장 RAM 카트리지(1MB)가 필요합니다(원본과 같음).
- 옵션 LANGUAGE 에서 ENGLISH·SPANISH 를 고르면 오프닝 스토리·캐릭터 소개가 깨집니다. JAPANESE 로 두세요.
- 글자 칸이 모자라 엔딩 대사 일부는 짧은 말로 옮겼습니다.
- 로딩 화면(WAKUWAKU NEXT MATCH·FIGHT! 등)의 영문 그림 글자는 원본 그대로입니다.
- 엔딩 스태프 롤은 원본 그대로입니다.

## 저장소 구성

- `tools/` — 추출·넣기(대사·WAK2·엔딩)·글꼴·기술표(CMP)·경고 화면 그림·디스크 빌드·배포 도구
- `data/번역/` — 번역 텍스트(대사·WAK2·엔딩·기술표·경고 화면)
- `data/font_map_src.txt` — 원본 글꼴 칸 대응표
- `docs/` — 조사 기록
